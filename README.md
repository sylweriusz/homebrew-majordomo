# homebrew-majordomo

Homebrew tap for [Majordomo](https://github.com/sylweriusz/majordomo) — local, on-device Whisper speech-to-text for macOS.

## Install

```bash
brew install --cask sylweriusz/majordomo/majordomo
```

The three-part name auto-taps this repo, so no separate `brew tap` step is needed. The cask strips the quarantine attribute, so the app launches without the Gatekeeper screen.

Website: <https://majordomo.pomr.uk>
